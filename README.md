# Pirate Arena

Аркадный шутер про пирата на палубе. Волны абордажников, ядра, монеты и мастерская между волнами.
Вся графика рисуется кодом — ни одного внешнего ассета, проект весит пару сотен килобайт.

## Как запустить

1. Скачай Godot 4 (версия 4.2 или новее): https://godotengine.org/download
2. Открой `project.godot` через «Import» в Godot (или перетащи файл в окно).
3. Нажми **F5** (или кнопку ▶ справа сверху).

Экспорт в `.exe`: `Project → Export → Add… → Windows Desktop`, дальше `Export Project`.

## iOS / iPhone

Готовый пресет `iOS` уже в `export_presets.cfg`, а `.github/workflows/ios.yml` собирает `.ipa` на macOS-раннере GitHub.
Подробная инструкция: [docs/IOS.md](docs/IOS.md).

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел |
| ЛКМ (зажать) | стрельба |
| Пробел | рывок (неуязвимость на 0.16 с) |
| R | рестарт после смерти |
| ESC | закрыть мастерскую (в магазине) |

## Что внутри

- **Волны.** Каждая волна сильнее: больше врагов, выше HP, быстрее спавн. Каждая 5-я волна — босс («капитан»).
- **Враги.**
  - `crab` — краб, лезет напрямик;
  - `wisp` — быстрый дух, летит зигзагом;
  - `gunner` — держит дистанцию и стреляет;
  - `brute` — толстый, медленный, больно бьёт;
  - `boss` — радиальные залпы из 12 ядер.
- **Монеты.** Падают с врагов, притягиваются в радиусе магнита. Тратятся в мастерской.
- **Мастерская** между волнами: 8 улучшений, цена растёт с уровнем.
  Урон, темп стрельбы, мультивыстрел, пробитие, скорость, HP, магнит, перезарядка рывка.
- **Смерть** — экран с очками и волной, рестарт по кнопке или `R`.

## Где что лежит

```
project.godot        настройки проекта (1280x720, canvas_items, GL Compatibility)
main.tscn            единственная сцена: Node2D + game.gd
icon.svg             иконка
scripts/
  game.gd            состояние игры, волны, спавн, столкновения, палуба и море
  player.gd          пират: движение, рывок, стрельба, отрисовка
  enemy.gd           пять типов врагов, ИИ, отрисовка
  bullet.gd          снаряды (свои и вражеские), шлейф
  coin.gd            монеты, магнит, вращение
  fx.gd              частицы, кольца, цифры урона, следы рывка
  hud.gd             HUD, титульный экран, мастерская, game over
```

## Быстрый тюнинг

- Баланс волн: `start_wave()` и `_pick_kind()` в `scripts/game.gd`.
- Цены и лимиты улучшений: массив `UPGRADES` в начале `scripts/game.gd`.
- Формулы статов: `recalc()` там же.
- Размер арены: константа `ARENA`.
- Оружие: `player_shoot()` (скорость 980, радиус 6).

Всё столкновения считаются по расстояниям между кругами — физику Godot трогать не нужно,
поэтому игра одинаково ведёт себя на любом FPS.
